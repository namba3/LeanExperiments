## 階乗

対象: `LeanExperiments/Verification/Factorial/Spec.lean`

### 一般証明

- 末尾再帰実装が数学的な再帰仕様と任意の入力で一致します。
- 正値性、単調非減少性、`1 ≤ m < n` のときの狭義単調性（`0! = 1!` を除く）を示しています。
- `2^n ≤ (n+1)!`、`n! ≤ n^n`（`0^0 = 1`）、`1 ≤ k ≤ n` なら `k ∣ n!`、および `m! ∣ n! ↔ m ≤ n ∨ (m = 1 ∧ n = 0)` を証明しています。
- 任意の有限集合について、各要素の階乗の積が引数の合計の階乗を割り切ることと、階乗の加法を上昇階乗との積に分ける恒等式も示しています。
- `2 ∣ n! ↔ 2 ≤ n` と `n! % 2 = 1 ↔ n ≤ 1` を示しています。

### 検証範囲

有限領域を列挙した検査はありません。任意入力の一致定理が実装の正当性を支えています。

## Fibonacci

対象: `LeanExperiments/Verification/Fibonacci/Spec.lean`

### 一般証明

- 高速倍加法実装が、通常の漸化式で定義した仕様と任意の添字で一致します。実装の漸化式、正値性、単調性、添字2以降の狭義増加も示しています。
- 倍加法が返す二項の正値性・大小関係に加え、実装値が0となるのは添字0の場合に限ることも示しています。
- 加法公式 `F(m+n+1) = F(m)F(n) + F(m+1)F(n+1)`、倍加公式、累積和・二乗和の恒等式、隣接項が互いに素であることを証明しています。
- 成長評価 `2^n ≤ F(2n+1)`、`2^(n/2) ≤ F(n+1)`、`F(n) ≤ 2^n` を示しています。
- 指定した周期直前・周期位置の剰余条件から一般の周期定理を導き、有限個の剰余代表の確認を任意の添字の整除同値へ持ち上げる補題があります。
- 偶数判定 `2 ∣ F(n) ↔ 3 ∣ n` と、以下の整除同値を証明しています。

- 添字 `0..512` の連続範囲で実装と仕様を照合します。
- `2..65,536` の2冪の直前・該当値・直後を確認します。
- `F(100)` と `F(1000)` の正確な値を確認します。

## 素因数分解

対象: `LeanExperiments/Verification/PrimeFactors/Spec.lean`

### 一般証明

- 入力が1以下なら実装が空配列を返すことを、任意の入力に対して証明しています（0・1の個別定理はこの一般定理から導出）。
- 試し割り候補を `d`、残余を `r` とすると、停止測度 `r - d` は、割り算で残余を更新する場合と候補を1増やす場合の両方で減少することを一般補題で証明しています。
- 試し割りループの任意入力契約として、出力済み因子の積と残余の積が入力に等しいこと、候補が常に2以上であること、および出力済み因子が全て2以上であることを不変条件付きで証明しています。
- ループ契約から実装の返却配列まで接続し、入力が2以上なら返却因子の積が入力に等しいことを任意の入力について証明しています。
- 同じ不変条件から、入力が2以上なら返却配列に含まれる因子が全て2以上であることも証明しています。
- 試し割り候補より小さい2以上の数が残余を割らないことを、任意の入力に対するループ不変条件で証明しています。割り算で残余を更新する場合は、商の約数が除算前の残余も割ることを使い、候補を進める場合は直前の候補が割らないことを使います。
- この不変条件と現在候補が残余を割る条件から、試し割りループが配列へ追加した因子は全て素数であることを証明しています。
- ループ終了後の残余が1以下または素数なら、返却配列が積・昇順性・素数性からなる独立仕様 `FactorsCorrect` を満たす条件付き合成定理があります。さらに、次の停止状態と Mathlib の最小素因数評価を使う一般証明でこの仮定を実装から導き、無条件の `primeFactors_correct` へ接続しています。
- 終了状態を含むループ不変条件から、停止時に候補の平方が残余を超えることを証明しています。残余が合成数だと仮定すると、Mathlib の最小素因数平方評価により最小素因数が現在候補より小さくなり、約数排除の不変条件に反するため、残余は1より大きければ素数です。
- 以上を合成し、`primeFactors_correct` で任意の自然数について実装結果が独立仕様 `FactorsCorrect` を満たすことを証明しています。
- 非零な二入力について、積の実装出力が各入力の実装出力を連結して併合ソートした列と一致します。仕様の乗算閉包と一意性を実装へ接続した合成則です。0は空因数列として扱うため、仮定から明示的に除外します。
- 非零な二入力について、積の実装出力における任意の値の出現回数は、各入力の出現回数の和になります。列の並び順に依存せず、素数以外の値についても成り立つ重複度の加法則です。
- 全入力について、最大公約数・最小公倍数の重複度を特徴付けています。両入力が非零なら gcd では小さい方、lcm では大きい方となり、0を含む場合はこの仕様の空因数列規約に沿った結果になります。
- 任意入力の任意の自然数べきについて、実装出力を仕様上の反復併合列と同一視します。0ではべきの結果が0または1となり、両方の空列仕様で境界を処理します。各値の出現数が指数倍になる定理も仮定なしで成り立ち、素数以外の値も個数0として含めます。
- 入力が2以上なら、返却配列の各因子が2以上で入力を割り切り、入力以下であることを一つの一般定理にまとめています。整除性は因子積の性質と積保存定理から導きます。
- 任意の入力で、返却された各因子が素数であり、入力を割り切り、入力以下であることを一つの一般定理にまとめています。1以下では返却列が空なので条件は空虚に成立します。
- 候補の単調増加と各段階の出力上界をループ不変条件にし、停止時の残余を含めて返却因子列が昇順であることを証明しています。
- 有限素数判定器を、真の約数がない条件と乗法的な素数条件に結び付けています。
- 正しい因数列から、因子の素数性、2以上、入力を割り切ること、入力以下であることを導きます。
- 入力が2以上なら因数列が空でなく、積が入力に一致します。因数列が長さ1であることと入力が素数であることは同値です。
- 非零入力について、素数の `k` 乗が入力を割り切ることと、その素数が実装の返却配列に `k` 回以上現れることが同値です。
- 因子数を `k` とすると `2^k ≤ n` です。正しい因数列の一意性と、空列になる入力が0または1に限ることも証明しています。
- 二つの正しい因数列が一致する条件は、入力が同じか、入力がどちらも0または1であることと同値です。実装出力についても同じ特徴付けが成り立ち、空配列にまとめられる0と1だけが異なる入力でも同じ結果を返します。
- より一般に、非零の約数が入力を割り切ることを、約数の各素数指数と実装結果中の出現数を比べる同値として特徴づけています。
- さらに、非零入力が平方因子を持たないことと、実装の返却配列に重複因子がないことを同値として示しています。
- 正の指数のべきであることも、返却配列で各素数が現れる回数がその指数で割り切れることと同値です。これは平方数の偶数重複数条件を任意の正の指数へ広げます。
- 実装が返す任意の値の重複数は `Nat.factorization` の指数と一致します。素数でない値の出現数も0だと分かります。

### 有限確認

- `0..20,000` の全入力で積・昇順性・素数性を確認します。
- `49²`、`121²`、`961²`、`1009²`、`10007²`、`1000003²` の前後や、大きな素数・半素数・重複因子を確認します。
- `2⁶⁴−1 = 3·5·17·257·641·65537·6700417`、`2⁶⁴` の64個の2、`2¹²⁸` と `2²⁵⁶` の分解も完全な仕様と照合します。

### 一般証明の状況

素因数分解実装の一般的な仕様適合は証明済みです。ここでいう仕様は、1以下の入力では空列、2以上では積の保存・昇順性・各因子の素数性です。有限確認は、一般証明に加えて具体的な境界値や大きな値を回帰確認する役割を持ちます。
