# 検証カタログ

各アルゴリズムの証明範囲を、任意入力の一般証明と有限領域の計算確認に分けて整理します。有限確認は列挙した入力だけを対象とし、一般証明の代わりにはしません。

## 概要

| 領域 | 任意入力の証明 | 証明境界・状況 |
| --- | --- | --- |
| [CLI 入力](verification/stateful.md#cli入力) | 空白分割と文字リスト仕様の一致、複数値・単一値パーサーと `List.mapM` 仕様の一致 | 標準入力の IO 層 |
| [階乗](verification/arithmetic.md#階乗) | 実装と再帰仕様の一致、増加性・上下界・整除性 | 実装の一般正当性を証明済み |
| [Fibonacci](verification/arithmetic.md#fibonacci) | 高速倍加法と再帰仕様の一致、漸化式・加法公式・周期性など | 実装の一般正当性を証明済み |
| [素因数分解](verification/arithmetic.md#素因数分解) | `FactorsCorrect` に対する任意入力の実装正当性、仕様由来の因数列の性質・一意性、積保存・各因子の範囲・整除性・昇順性、ループ不変条件 | 一般証明を完了。有限確認は境界値・大きな値の回帰範囲 |
| [ソート](verification/sorting.md) | quick sort・merge sort・heap sort の再帰版とループ版について、任意入力での仕様適合と独立検査器への合格。全ソートCLIの純粋出力文字列が独立な MergeSort と一致 | 各実装の一般正当性を証明済み。標準入出力の IO 層は対象外 |
| [逐次中央値](verification/stateful.md#逐次中央値) | 任意の不変状態への任意値挿入保存、任意長 `ofArray` の状態不変条件、全接頭辞検査器の成功、独立ソート仕様との中央値およびCLI表示の一致、入力順列に対する不変性 | 一般証明を完了。有限確認は別記の領域に限定 |

## 有限確認の範囲

| 領域 | 有限確認 |
| --- | --- |
| CLI 入力 | 空・空白・不正値・大きな整数などのパーサー境界例 |
| 階乗 | 有限領域を列挙した検査なし |
| Fibonacci | 添字0〜512、2冪前後、代表値 |
| 素因数分解 | 0〜20,000、平方数近傍、大きな値 |
| ソート | 網羅入力、境界長、64 bit 値 |
| 逐次中央値 | 87,381件・97,656件の網羅領域と境界列 |

## 保証範囲と信頼依存

検証結果は「入力範囲」と「証明の信頼依存」を別々に読みます。

| 表示 | 入力範囲 | 信頼依存 |
| --- | --- | --- |
| A | 任意入力に対する一般定理 | Lean カーネルが扱う許容公理（`propext`、`Classical.choice`、`Quot.sound`）のみ |
| B | 任意入力に対する一般定理 | A の公理に加え、`native_decide` が生成する補助公理に依存する定理 |
| C | 名前・定義で明示した有限領域 | 有限領域の計算確認。ネイティブ計算由来の依存の有無は、監査結果で別に確認 |

C は証明範囲の区分であり、信頼依存の区分とは独立です。CI は A/B の一般定理と private 補助定理、C の有限確認を別グループで監査し、`sorryAx` と未登録の依存を拒否します。B に分類される定理も任意入力を対象にした一般定理ですが、A と同じカーネル依存だけで閉じているとは扱いません。

GitHub Actions の実行サマリーには、一般証明・有限確認ごとに `native_decide` 由来の補助公理へ依存する件数を分けて表示します。分類は登録済み監査出力から毎回計算され、README の固定件数にはしません。

新しい Lean 利用側では、実行可能アルゴリズムだけなら `LeanExperiments.Algorithms`、仕様・証明も必要なら `LeanExperiments.Verification` を import してください。歴史的な `LeanExperiments` 集約 import は互換性のため両方を読み込みます。

## 継続的ビルド

GitHub Actions は `lake build` と CLI の入出力スモーク確認に加え、監査スクリプトの回帰テストを実行します。Lean ソース全体から `sorry`・`admit`・独自 `axiom`／`constant` 宣言を検出し、Verification 配下の公開一般定理、private 補助定理、有限回帰検査・具体例のカーネル依存を個別に監査します。private 名がimport後に隠れるmodule-system形式では、元ソースを監査時に再コンパイルして依存を取得します。通常の一般定理とprivate定理の依存は `propext`・`Classical.choice`・`Quot.sound` に限定します。一般的な帰納証明の基底値や有限剰余表の証明に `native_decide` を使う定理は、通常の一般定理とは別グループに明示して監査し、生成された補助公理の対象を有限検査グループと合わせて登録済み定理に限定します。Verification 配下の全 Lean ファイルを一般定理・有限検査の各ソース一覧と照合し、定理やファイルの追加・削除による監査漏れと古い登録を検出します。全監査で `sorryAx` と未登録の定理依存を拒否し、実際の依存から一般証明・有限検査とネイティブ計算依存の件数をActionsサマリーへ出力します。ビルド成功は Lean が受理した定義・証明の確認です。有限計算確認と、形式検証の対象外である CLI の標準入出力実行は別の証拠です。
